# `@sanely/core`

Shared internal definitions for the Sanely libraries. This workspace stays private; its consumers bundle its JavaScript and declarations.

The `@sanely/core/time` entry point provides time unit definitions, aliases, conversion constants, and derived types.

Read the [architecture](docs/architecture.md), [testing guide](docs/testing.md), and root [contributor guide](../../CONTRIBUTING.md#share-internal-code) before changing the package.
