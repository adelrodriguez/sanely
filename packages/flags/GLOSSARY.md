# `@sanely/flags` Context

`@sanely/flags` is a provider-independent, type-safe feature-flag library for TypeScript applications. Package consumers declare flags as values, write or install a provider, and read flags through a reader. The package runs the evaluation lifecycle, hooks, validation, and fallback behavior.

A flag definition is data: a key, a default, and optional variants and payload parser. A provider decides flags for an identity through one of two methods, and its identity type comes from the annotation on its `identity` parameter. `createFlags` binds one provider and an optional identity source into a reader. A reader with `identify` reads directly. A reader without it reads only through `for(identity)`. Reads never reject: a failed evaluation returns the flag's default, and its evaluation details carry a tagged error.

A reader can evaluate several flags at once. The batch resolves the identity once, keeps each flag's lifecycle and fallback, and sends each flag key to the provider once in a flush round. A store and request coalescing let evaluations share decisions. Hooks are observers.

For server rendering, a reader makes a snapshot of flag values for one identity, and the React flag provider renders from it first. React support is an optional integration at `@sanely/flags/react`. Test helpers are at `@sanely/flags/testing`.

Use the vocabulary below in code, tests, issues, and documentation. The package's public entry points are `@sanely/flags`, `@sanely/flags/react`, and `@sanely/flags/testing`.

## Language

| Term                    | Meaning                                                                                                                                                                                                                                                                              |
| ----------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ |
| **flag**                | A feature flag that a reader evaluates to a value. Code refers to a flag through its flag definition.                                                                                                                                                                                |
| **flag definition**     | The frozen value from `flag.boolean` or `flag.variant`: a flag key, a default value, and, for a variant flag, its variants and optional payload parser. It holds no provider and no identity.                                                                                        |
| **flag key**            | The key that names a flag in the provider. Two flag definitions with the same flag key ask the provider about the same provider flag.                                                                                                                                                |
| **boolean flag**        | A flag that evaluates to `true` or `false`.                                                                                                                                                                                                                                          |
| **variant flag**        | A flag that evaluates to one of its string variants.                                                                                                                                                                                                                                 |
| **payload parser**      | The function on a variant flag that turns the raw payload of a decision into a typed payload.                                                                                                                                                                                        |
| **provider**            | The value from `defineProvider` that decides flags for an identity, through either `decideOne` for one flag or `decide` for several flags. It can also report flag changes.                                                                                                          |
| **reader**              | The value that `createFlags` returns, or that `for(identity)` returns. It evaluates any flag definition with one provider.                                                                                                                                                           |
| **decision**            | A provider or stored result with an explicit `type` discriminant: either `{ type: "boolean", value }` or `{ type: "variant", variant, payload? }`.                                                                                                                                   |
| **evaluation details**  | The result of one evaluation: the returned value, the flag key, the source (`cache`, `provider`, or `default`), and a parsed payload or an evaluation error when present.                                                                                                            |
| **evaluation error**    | The tagged error in evaluation details that says why an evaluation returned the default.                                                                                                                                                                                             |
| **identity**            | The provider-specific subject of an evaluation. It extends `Identity`, which requires `distinctId`.                                                                                                                                                                                  |
| **anonymous**           | The value that stands for an evaluation without an identity. A provider accepts it only when its identity type includes it. Anonymous evaluations are never stored or coalesced.                                                                                                     |
| **evaluation context**  | What one evaluation is about: the flag definition, the identity once it resolves, and the evaluation's signal. Hooks and the evaluation key function receive it.                                                                                                                     |
| **snapshot**            | Serializable flag values that a reader evaluated for one identity, with each value's source and error tag, so a client can render the same values first.                                                                                                                             |
| **evaluation key**      | The collision-safe string that the store and request coalescing use to identify interchangeable evaluations of one flag for one identity. It holds the provider name, the flag key, the flag shape, and the typed `distinctId` by default. A consumer `key` function can replace it. |
| **store**               | A consumer `DecisionStore` that the reader reads before provider work and writes after a valid provider decision. The store owns serialization and expiry.                                                                                                                           |
| **request coalescing**  | Built-in behavior that lets concurrent evaluations with one evaluation key share provider work after store reads. Each evaluation keeps its own error, fallback, and cancellation path.                                                                                              |
| **leader / follower**   | The request-coalescing roles for one evaluation key. The leader calls the provider and writes the store. Followers attach to the leader's in-flight call and reuse its decision.                                                                                                     |
| **batch**               | Several flags that a reader evaluates together after one identity resolution, through `getMany`, `detailsMany`, `snapshot`, or React's `useFlags`.                                                                                                                                   |
| **flush round**         | One provider request that a batch shares between its flags that need provider work in the same tick. Each flag key joins a round once.                                                                                                                                               |
| **change broadcaster**  | The reader's single attachment to the provider's `subscribe` function. It sends each change notification to invalidation and to every reader listener, and it attaches at most once at a time.                                                                                       |
| **hook**                | A lifecycle observer with optional `before`, `after`, `error`, and `finally` handlers. A hook cannot change an evaluation's result.                                                                                                                                                  |
| **error report**        | What `onError` receives for a failure outside an evaluation's result: a hook failure, a store failure, or a provider `subscribe` failure.                                                                                                                                            |
| **flag cache**          | The bounded React promise cache that each React flag provider mount owns. It holds evaluations for each list of flags and identity.                                                                                                                                                  |
| **flag provider**       | The React `FlagsProvider` that supplies a reader, an identity, a snapshot, and a flag cache to the hooks below it.                                                                                                                                                                   |
| **integration**         | An optional framework-facing package surface built on the core API, such as the React integration.                                                                                                                                                                                   |
| **package consumer**    | An application or library that installs `@sanely/flags` and imports its published package entry points.                                                                                                                                                                              |
| **public entry points** | The supported import paths: `@sanely/flags`, `@sanely/flags/react`, and `@sanely/flags/testing`.                                                                                                                                                                                     |

Call the provider result a decision, not a "flag value". A flag returns its value, which is the default when the evaluation falls back. Use "decision" when the difference between the two matters. Call the React `FlagsProvider` the flag provider, and the `defineProvider` value the provider.
